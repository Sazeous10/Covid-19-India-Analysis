# 🦠 COVID-19 India Data Analysis

This project presents a **comprehensive analysis** of COVID-19 data in India, focusing on case trends, vaccination progress, and state-wise insights. Utilizing tools like **Pandas**, **Seaborn**, and **Plotly**, the analysis reveals patterns and correlations critical for understanding the pandemic's impact.

---

## 📊 Project Overview

- 📅 **Data Source**: COVID-19 case and vaccination datasets from India.
- 📌 **Focus Areas**:
  - Case trends: Confirmed, Recovered, Deaths
  - Vaccination analysis
  - State-wise comparisons
  - Demographic and regional insights

---

## 🧰 Tools & Libraries Used

- `Pandas`, `NumPy` – Data manipulation
- `Matplotlib`, `Seaborn` – Static visualizations
- `Plotly Express`, `Plotly Subplots` – Interactive visualizations
- `datetime` – Date processing and filtering

---

## 📂 Dataset Used

- **COVID Case Data**: `covid_19_india.csv`
- **Vaccination Data**: `covid_vaccine_statewise.csv`

---

## 🚀 Key Insights

- 📈 Identified states with **highest active cases and death rates**.
- 🧑‍🤝‍🧑 Found demographic trends (e.g., **60% male cases**, age patterns).
- 💉 Analyzed **vaccine distribution** across states over time.
- 🗺️ Interactive charts for **regional case trends** and **vaccination rates**.

---

## 📊 Visualizations

- Time-series line charts for case progression.
- Bar plots for state-wise comparisons.
- Heatmaps for daily case intensity.
- Interactive dashboards using **Plotly**.

## 📦 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/covid19-india-analysis.git
   cd covid19-india-analysis
   ```

2. Open the Jupyter Notebook:
   ```bash
   jupyter notebook "Covid 19 Analysis.ipynb"
   ```

3. Run all cells to reproduce the analysis.
